관계 (Relationships)

1 : N — ON DELETE CASCADE
employees → attendance
직원 1명은 다수의 근태 기록을 가질 수 있습니다.
attendance.employee_id → employees.id
직원 삭제 시 관련 근태 기록도 함께 삭제됩니다.
1 : 0..N — ON DELETE SET NULL
projects → attendance
프로젝트는 선택 항목으로, 근태 기록에 없을 수 있습니다 (NULL 허용).
attendance.project_id → projects.id
프로젝트 삭제 시 해당 필드는 NULL로 변경됩니다.
1 : N — ON DELETE CASCADE
employees → unit_prices
직원 1명은 여러 월에 걸쳐 단가를 가질 수 있습니다 (월별 단가 이력).
unit_prices.employee_id → employees.id
(employee_id, month) 복합 UNIQUE 제약.
1 : N — ON DELETE CASCADE
employees → payment_schedules
직원 1명은 다수의 입금 예정 정보를 가질 수 있습니다 (캐시플로우).
payment_schedules.employee_id → employees.id
직원 삭제 시 관련 입금 예정도 함께 삭제됩니다.
