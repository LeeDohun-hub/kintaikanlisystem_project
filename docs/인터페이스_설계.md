# 인터페이스 설계（勤怠管理システム）

본 문서는 **HTTP REST API** 및 프론트엔드와의 연동 규약을 정리합니다. Base path는 **`/api`**이며, 개발 시 Vite가 동일 경로를 백엔드로 프록시합니다.

---

## 1. 공통 규약

### 1.1 전송·세션

| 항목 | 내용 |
|------|------|
| 프로토콜 | HTTP/HTTPS |
| 데이터 형식 | JSON（`Content-Type: application/json`）※ 파일 업로드는 `multipart/form-data` |
| 인증 | 서블릿 **HttpSession**（로그인 성공 시 세션에 `loginUser` 저장） |
| 클라이언트 | `axios` `baseURL: "/api"`, **`withCredentials: true`** |

### 1.2 CORS（백엔드 `WebConfig`）

- 패턴: `/api/**`
- 허용 오리진 예: `http://localhost:3000`, `http://localhost:5173`
- `allowCredentials: true`

### 1.3 인증·권한 적용 요약

| 구분 | 설명 |
|------|------|
| 비인증 허용 | `POST /api/auth/login`, `POST /api/auth/register`（인터셉터 제외） |
| 인터셉터 제외 기타 | `POST /api/auth/logout`, `GET /api/auth/me`（각 핸들러에서 세션 처리） |
| 로그인 필수 | 위를 제외한 대부분의 `/api/**` |
| 관리자 전용 | 컨트롤러 또는 메서드에 `@AdminOnly` — **403**（일반 메시지 JSON） |

### 1.4 공통 JSON 형식（`ApiResponses`）

| 상황 | HTTP | 본문 예 |
|------|------|---------|
| 성공 메시지 | 200 | `{"message":"..."}` |
| 잘못된 요청 | 400 | `{"error":"..."}` |
| 미인증 | 401 | `{"error":"Unauthorized"}` |
| 그 외 오류 | 가변 | `{"error":"..."}` |

로그인 실패: **401**, `{"error":"スタッフコードまたはパスワードが正しくありません。"}`（`AuthController`）.

관리자 전용 URL에 일반 사용자 접근: **403**, `{"error":"管理者のみアクセスできます。"}`.

### 1.5 날짜·시각（Jackson）

- 응답 `WorkTimeResponse`: 날짜 `yyyy-MM-dd`, 시각 `HH:mm`.
- 요청 `WorkTimeCreateRequest`: ISO-8601 호환（`LocalDate` / `LocalTime`）— 상세는 DTO 주석 참고.

## 2. API 목록

### 2.1 인증 ` /api/auth`

| Method | Path | 인증 | 설명 |
|--------|------|------|------|
| POST | `/auth/register` | 불필요 | 회원가입 |
| POST | `/auth/login` | 불필요 | 로그인（세션 생성） |
| POST | `/auth/logout` | — | 세션 무효화 |
| GET | `/auth/me` | 세션 있으면 200 | 현재 사용자 `LoginResponse` |

**`LoginRequest`（login）**

```json
{
  "employeeCode": "EMP001",
  "password": "secret",
  "role": "EMPLOYEE"
}
```

`role`: `ADMIN` | `EMPLOYEE`（로그인 화면 선택과 일치 필요）.

**`LoginResponse`（login / me）**

```json
{
  "id": 1,
  "employeeCode": "EMP001",
  "name": "山田太郎",
  "role": "EMPLOYEE"
}
```

**`RegisterRequest`（register）** — 필드: `employeeCode`, `name`, `department?`, `hourlyCost?`, `role`, `password`, `confirmPassword`（검증 메시지는 Bean Validation）.

---

### 2.2 직원 마스터 `/api/employees`（**ADMIN**）

| Method | Path | 설명 |
|--------|------|------|
| GET | `/employees` | 전 직원 요약 목록 |
| POST | `/employees` | 직원 등록 |

**응답 요소（`EmployeeSummaryResponse`）:** `employeeId`, `employeeCode`, `employeeName`, `department`, `hourlyCost`, `activeFlag`.

**요청（`EmployeeCreateRequest`）:** `employeeCode`, `employeeName`, `department?`, `hourlyCost?`, `activeFlag?`（0/1）.

---

### 2.3 근무 시간 `/api/worktime` 또는 `/api/work-time`（로그인 사용자）

동일 핸들러에 경로 2종（하위 경로 동일）.

| Method | Path | 설명 |
|--------|------|------|
| GET | `/worktime?month=YYYY-MM` | 월별 목록（역할에 따라 본인만 / 전원） |
| POST | `/worktime` | 단건 등록 |
| POST | `/worktime/bulk` | 벌크 등록·갱신（`WorkTimeBulkRequest`） |
| PUT | `/worktime/{id}` | 단건 수정 |
| DELETE | `/worktime/{id}` | 단건 삭제 |
| POST | `/worktime/import-kintaihyo` | `multipart/form-data` **file** — 勤務表 Excel |

**`WorkTimeCreateRequest`**

```json
{
  "workDate": "2026-04-01",
  "startTime": "09:00:00",
  "endTime": "18:00:00",
  "breakMinutes": 60,
  "remarks": "optional"
}
```

**`WorkTimeBulkRequest`**

```json
{
  "overwriteExisting": true,
  "items": [ { ... WorkTimeCreateRequest ... } ]
}
```

**`WorkTimeResponse`（요약）**  
`workId`, `employeeId`, `employeeCode`, `employeeName`, `workDate`, `startTime`, `endTime`, `breakMinutes`, `workMinutes`, `dailyWorkHm`, `cumulativeWorkHm`, `remarks`.

**`ImportAttendanceResponse`**  
`successCount`, `errorCount`, `updatedExistingDays`, `errors[]`（`row`, `message`）.

### 2.4 출근（設計書パス）`/api/attendance`（**ADMIN**）

| Method | Path | 설명 |
|--------|------|------|
| POST | `/attendance/import` | Excel 파일 일괄取込（`file`） |
| GET | `/attendance/summary?month=YYYY-MM` | 월별 통계（`MonthlyStatisticsResponse`） |

※ 대시보드·통계 화면은 주로 **`/api/statistics/monthly`**를 사용합니다（기능은 통계 서비스와 유사）.

---

### 2.5 통계 `/api/statistics`（**ADMIN**）

| Method | Path | 설명 |
|--------|------|------|
| GET | `/statistics/monthly?month=YYYY-MM` | 월별 전사 집계 |

**`MonthlyStatisticsResponse`**

```json
{
  "month": "2026-04",
  "totalWorkMinutes": 9600,
  "byEmployee": [
    {
      "employeeId": 1,
      "employeeCode": "EMP001",
      "employeeName": "山田太郎",
      "totalWorkMinutes": 480
    }
  ]
}
```

---

### 2.6 리포트 `/api/reports`（로그인 사용자）

| Method | Path | 설명 |
|--------|------|------|
| GET | `/reports/monthly.pdf?month=YYYY-MM` | **PDF**（`Content-Type: application/pdf`） |

- **ADMIN**: 전사 통계 + 상세 라인（해당 월·서비스 정책에 따름）.
- **EMPLOYEE**: 본인 통계 + 본인 상세.

## 3. 프론트엔드 연동

| 파일 | 역할 |
|------|------|
| `api/api.js` | 공통 Axios, 401 시 `/login` 리다이렉트（`auth/me` 등 일부 URL 제외） |
| `api/worktime.js` | 근무 API 래퍼 |
| `api/attendance.js` | 관리자取込 API |

---

## 4. 오류·제한 사항 메모

- 월 파라미터 형식 오류 시 **400**（`YYYY-MM`）.
- 비즈니스 규칙 위반 시 **400** + `error` 메시지（서비스에서 `IllegalArgumentException` 등）.
- 클라이언트는 401 시 세션 만료·미로그인으로 처리하고 로그인 화면으로 이동하는 현재 구현에 맞춤.
