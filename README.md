📘1. 근태관리 시스템 (개요)
1. 목적
본 트레이닝은 신입사원이 실제 업무에 가까운 업무 시스템을
설계·구현·운용하는 경험을 통해
Java 기반 업무 시스템 개발을 기초부터 응용까지 체계적으로 습득하는 것을 목적으로 한다.
대상 시스템은
현장(파견지)에서 근무하는 모든 직원의 근무표(근태)를 관리하는 시스템이다.
________________________________________
2. 시나리오 (업무 개요)
2.1 사용자 구분
① 직원
•	현장에서 개인 PC, 모바일, Excel 폼을 통해 근무 정보를 입력 
② 관리자
•	매월 전체 직원 근무 현황 집계 및 확인 
•	가동률, 매출, 손익, 캐시플로우 파악 
________________________________________
업무 흐름
•	직원이 매일 근무 시작/종료, 휴식 시간, 업무 내용 입력 
•	근무 데이터가 실시간으로 서버에 저장 
•	관리자가 월별 / 직원별 / 프로젝트별 집계 확인 
•	가동률, 청구 예정 금액, 입금 예정 금액 자동 계산 
•	캐시플로우 및 미래 예측 확인 
________________________________________
3. 시스템 구성
3.1 하드웨어
•	서버: Linux 
•	클라이언트: Windows 
3.2 소프트웨어
백엔드
•	Java 
•	Spring / Spring Boot 
•	Apache Tomcat 
프론트엔드
•	JavaScript 
•	React

•	MySQL Workbench 
기타
•	REST API (JSON)

•	개발환경: Eclipse 
•	서버 접속: TeraTerm 
________________________________________
4. 기능 개요
4.1 직원 기능
•	근무 입력 
•	근무일 
•	시작/종료 시간 
•	휴식 시간 
•	근무 구분 (일반 / 야근 / 휴일) 
•	코멘트 
조회 기능
•	자신의 월별 근무 내역 
•	총 근무 시간 확인 
________________________________________
4.2 관리자 기능
① 근태 관리
•	전체 직원 목록 조회 
•	일별 / 월별 / 직원별 검색 
② 집계 및 분석
•	직원별 근무 시간 집계 
•	가동률 계산 (근무시간 ÷ 기준시간) 
•	프로젝트별 집계 
③ 매출 / 손익 관리
•	직원 단가 관리 
•	월별 매출 자동 계산 
•	인건비 입력 
•	손익 계산 
④ 캐시플로우 예측
•	입금 예정일 관리 
•	월별 입금 예정 금액 시각화 
•	향후 몇 개월 예측
